# User acceptance of information technology
User acceptance of information technology: system characteristics, user perceptions and behavioral impacts

Summary:

The paper takes into account how design features help people to use the system. The most prominent finding was that “perceived usefulness” was 50% more influential than “ease of use” in determining the usage of the system. Thus, this emphasizes the significance of the functional features of the system.

The technology acceptance model (TAM) specifies behavior of the users. TAM provides the overall view of design choices that could impact user acceptance. Therefore, it would help in predicting and evaluating user acceptance of information systems. Diagnostic features defined in TAM could help in identification and evaluation of user acceptance strategies.

User acceptance is one of the important factors that make information systems successful. The paper determines not only the factors that make any system unacceptable but it also focuses on the factors on improving the design aspects that could improve the acceptance criteria. There is a need of a model that could gauge how design choices impact user acceptance.

The attitude of the users is an important determinant in finding if he will use it or not? Attitude of the user depends on: “perceived usefulness” and “perceived ease of use”. The perceived ease of use unintentionally impacts the “perceived usefulness”. The system design features indirectly (through perceived usefulness and perceived ease of use) impacts the attitude of using the IS and actual usage behavior of the user. Behavior refers to “the subjective likelihood that performing the behavior will lead to a specified outcome”. Attitude toward the behavior is an evaluation of the behavior.

By analyzing the computer user behavior, the study determines the influence of system characteristics on user attitude and usage. Earlier research shows that perceived usefulness and perceived ease of use are one of the important criteria for user acceptance of IS.

Perceived usefulness is defined as” The degree to which an individual believes that using a particular system would enhance his or her job performance.”

Perceived ease of use is defined as “The degree to which an individual believes that using a particular system would be free of physical and mental effort.”

As per two factor analysis suggested by (Davis, 1989), perceived ease of use and perceived usefulness are two distinct features. Perceived ease of use directly impacts perceived usefulness but vice versa is not true. People find easy to use systems more useful. Therefore, in order to make system more useful, the designer should either add new functional features or make the existing functions easier to use. Users could use difficult interface to accomplish their tasks but easier to use interface that does not help them in performing their job could not be accepted.

The key factor in the user acceptance of information systems is lack of user friendliness and this could be overcome by adding user interfaces that increase usability.
